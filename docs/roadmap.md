# Roadmap

This roadmap captures the current direction for `@urartian/loopback4-odata`.

## Near-term priorities

- stabilize the v1 public API and supported configuration surface
- complete remaining release checklist items
- keep PostgreSQL as the documented and supported SQL path
- improve test coverage in the remaining low-coverage runtime areas
- keep production guidance current for deployment, observability, and security

## Follow-up priorities

- evaluate additional database support only after the PostgreSQL path remains stable
- improve dev-tooling dependency health over time
- continue tightening generated API surface and contract review discipline
- expand examples and operator guidance based on real adopter needs

## Out of scope for v1

- broad multi-database support claims
- hosted SaaS policy or product terms
- heavy governance overhead beyond what the current project size needs

This roadmap is intentionally lightweight and should be updated as release
priorities change.
